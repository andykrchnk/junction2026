How to interpret this experiment

Wall evidence combines the saved model wall/railing head with source ink and short supported gap bridges. The notch variant adds small low-wall-evidence areas near the existing footprint, capped at 3% expansion. The image-face variant rebuilds walls from source strokes near model wall evidence and high-probability wall cores; it can enter areas covered by v2 wall polygons.

These are heuristics, not reliable classifiers for furniture, stairs or text. V4 can lose walls or create extra splits. All shapes require review. Region IDs are new; parent v2 IDs remain in the downloads. Names and confidence values are not inferred. Earlier predictions, the Decisions API work and the inference service are preserved.
