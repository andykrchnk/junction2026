name: pr-description
description: Write concise factual PR titles and descriptions with optional visual demonstrations.
---

Use a Conventional Commit title naming the final change. Read back the saved title and description before handoff. Follow the existing default branch in CONTRIBUTING.md.

Use `## What was done` for short bullets describing resulting behavior and `## What was changed` for concrete implementation changes. Use `## Verification` for checks and honest limitations. Include `## Demo` only when a screenshot or video exists; caption what it demonstrates and disclose mocked data or unavailable integration. Never publish local-only files or credentials. Use a body file with gh for multiline descriptions. Creating a description does not authorize publishing unless the user requested a PR.
